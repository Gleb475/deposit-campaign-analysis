# Банковская кампания: кто оформляет вклад

Анализ открытого датасета UCI Bank Marketing: 41 188 наблюдений телефонной кампании
португальского банка за 2008–2010 годы. SQL используется для срезов, Python — для загрузки,
проверки качества и графиков. Цель — выбрать гипотезы для следующей кампании.

## Результат

Оформлением вклада закончились 4 640 наблюдений: **11,27%**.

| Срез | Наблюдения | Оформления | Конверсия |
|---|---:|---:|---:|
| cellular | 26 144 | 3 853 | 14,74% |
| telephone | 15 044 | 787 | 5,23% |
| Успешная предыдущая кампания | 1 373 | 894 | 65,11% |
| Нет предыдущего результата | 35 563 | 3 141 | 8,83% |
| Один контакт в текущей кампании | 17 642 | 2 300 | 13,04% |
| Шесть и более контактов | 3 385 | 186 | 5,49% |

![Каналы](reports/contact.png)

У cellular выше наблюдаемая конверсия, но каналы не распределялись случайно.
По этим данным нельзя обещать рост от перевода звонков на другой канал.
Успешный прошлый контакт выделяет небольшой сегмент с высокой конверсией.
При этом самая большая доля оформлений приходится на admin. — 29,14% всех успехов,
хотя по конверсии этот сегмент уступает студентам и пенсионерам.

Частые контакты связаны с более низкой конверсией. Возможна обратная причинность:
труднее убедить клиента — требуется больше попыток. Поэтому ограничение числа звонков
стоит проверять отдельным экспериментом, а не вводить по одному срезу.

## Качество и ограничения

Найдено 12 полностью совпадающих строк. Без ID клиента нельзя установить, это дубли
или разные люди с одинаковыми признаками. В основном расчёте строки сохранены.
`unknown` учитывается как отдельное значение; пропуски не заполняются догадками.
Код 999 в pdays означает отсутствие предыдущего контакта, а не 999 дней ожидания.

`duration` известен после звонка и не используется для отбора клиентов до контакта.
Месяцы объединяют несколько лет: по ним нельзя построить полноценный временной ряд
или доказать сезонность. У набора нет устойчивого ID клиента и суммы привлечённого вклада:
retention, выручка, ROI и стоимость контакта здесь не рассчитываются.

## Запуск

Python 3.11+. Из папки проекта:

```text
python -m pip install -r requirements.txt
python analysis.py
python -m unittest discover -s tests -v
```

На Windows можно использовать `py` вместо `python`. Данные уже включены.
`analysis.ipynb` содержит тот же разбор с сохранёнными результатами.
Агрегаты и графики находятся в `reports/`, запросы — в `sql/`.

Источник и лицензия: [data/SOURCE.md](data/SOURCE.md). Учебный проект;
результаты не описывают клиентов или кампании Т-Банка.
